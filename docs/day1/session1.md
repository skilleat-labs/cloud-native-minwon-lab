## 이론 — NHN Cloud와 계정 구조

### NHN Cloud란?

NHN Cloud는 국내 기업 NHN이 운영하는 퍼블릭 클라우드 서비스입니다.  
이 실습에서는 **일반 퍼블릭 클라우드** 콘솔(`console.nhncloud.com`)을 사용합니다.

### 클라우드 계정 유형

이 실습에서는 두 가지 계정 유형을 구분해야 합니다.

| 구분 | NHN Cloud 계정 | IAM 계정 |
|------|---------------|---------|
| 생성 방법 | 이메일로 직접 가입 | 조직 관리자가 발급 |
| 주요 역할 | 조직 생성·결제 관리 | 프로젝트 내 작업 수행 |
| 로그인 주소 | `console.nhncloud.com` | `gov-cloud.console.nhncloud.com` |
| 이 실습에서 | 강사(조직 관리자)가 사용 | **수강생이 사용** |

> 수강생은 **IAM 계정**으로 콘솔에 접속합니다.

### 조직과 프로젝트 계층 구조

NHN Cloud의 자원 관리는 **조직 → 프로젝트 → 자원** 계층으로 구성됩니다.

```
조직 (Organization)  ← 사람과 돈을 관리하는 최상위 단위
 └── 프로젝트 A       ← 실제 자원(VM·네트워크·스토리지)이 담기는 그릇
 └── 프로젝트 B
      └── 자원들 (VM, VPC, Storage ...)
```

| 계층 | 조직 | 프로젝트 |
|------|------|---------|
| 역할 | 사람·비용 통합 관리 | 자원 생성·운영 |
| 주요 기능 | IAM 계정 발급, 결제 수단 관리, 구성원 권한 부여 | 서비스 활성화, 자원 생성·삭제, 비용 확인 단위 |

## STEP 01 — 콘솔 로그인

> **이 단계에서 할 일**: IAM 계정으로 콘솔에 접속해 로그인합니다.

### 로그인 방법

1. **[https://gov-cloud.console.nhncloud.com](https://gov-cloud.console.nhncloud.com)** 으로 접속합니다
2. IAM 계정 ID와 비밀번호를 입력합니다
3. 2단계 인증(이메일 또는 OTP)을 완료합니다

![콘솔 홈 화면](./images/01-console-home.png)

---

## STEP 02 — 조직과 프로젝트 확인

> **이 단계에서 할 일**: 내가 속한 조직과 프로젝트를 콘솔에서 직접 확인합니다.

### 실습

1. 화면 왼쪽 상단에서 **조직 이름**을 확인합니다
2. 조직 아래에서 **`minwon-service-edu{내 번호}`** 프로젝트를 선택합니다  
   예: `gov1.edu3` 계정이면 → `minwon-service-edu3`

![조직과 프로젝트 화면](./images/02-org-project.png)

> 프로젝트가 보이지 않으면 강사에게 프로젝트 멤버 추가를 요청하세요.

|------|-------------|

| 프로젝트 이름 | |

## STEP 03 — 내 프로젝트 생성

> **이 단계에서 할 일**: 조직 구조를 이해했으니, 이제 내 실습용 프로젝트를 직접 만들어봅니다.

### 콘솔 경로

```
콘솔 홈 > 조직 선택 후 > 프로젝트 만들기
```

### 생성 방법

1. 콘솔 상단에서 현재 **조직 이름**을 확인합니다
2. **프로젝트 만들기** 버튼을 클릭합니다
3. 아래 규칙으로 프로젝트 이름을 입력합니다

| 항목 | 값 |
|------|-----|
| 프로젝트 이름 | `minwon-service-edu{내 번호}` (예: `minwon-service-edu1`, `minwon-service-edu2`) |
| 설명 | 자유 입력 |

4. **확인** 버튼을 클릭합니다
5. 방금 만든 프로젝트가 목록에 나타나는지 확인합니다

!!! tip "내 번호 확인"
    강사가 배부한 계정 목록에서 본인 번호를 확인하세요.
    예: 계정이 `gov1.edu1`이면 프로젝트 이름은 `minwon-service-01`

!!! info "프로젝트와 자원"
    방금 만든 프로젝트는 비어있는 상태입니다.
    이후 STEP에서 서비스를 활성화하고 자원을 하나씩 채워갑니다.

### 내 프로젝트 기록

## 참고 — 내 IAM 계정은 어떻게 만들어진 걸까요?

수강생 여러분은 강사가 미리 발급한 IAM 계정으로 로그인했습니다.  
IAM 계정은 NHN Cloud 계정과 달리 **조직 안에서만 존재**하기 때문에, 조직 관리 화면 안의 멤버 관리에서 생성하고 관리합니다.

```
조직 → 멤버 관리 → IAM 계정 탭
```

![IAM 계정 관리 화면](./images/04-iam-create.png)

!!! info "수강생은 직접 만들 필요 없어요"
    이 화면은 **강사(조직 관리자)**만 접근할 수 있습니다.  
    수강생은 발급받은 계정으로 로그인만 하면 됩니다.
